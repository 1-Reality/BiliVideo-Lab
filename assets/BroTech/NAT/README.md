我们知道 RFC 5780理论上是更准的 NAT 测试方式，但目前互联网上有广泛的基于 WebRTC 的测试，例如 mao.fan，checkmynat.com。在不同的条件下，可能会产生不同结果。

经典的 NAT 分为四种类型：
1. NAT 1，全锥型，
2. NAT 2，IP 地址受限锥型。
3. NAT 3，端口受限锥型。
前三者都是 EIM，分别对应 EIF、ADF、APDF.
现实中的 ADF 非常稀有，根据小鲸社长统计只有大约 2/1000。如果直接获得公网 IP，但是有防火墙的，可能还有少量 Restricted Cone，但这并不妨碍真正的 NAT 2 极端稀有的事实。
4. NAT 4，对称型；还有俗称 4.5 的端口随机

有些时候，当端口发生多次变化时，基于 WebRTC 的原理会测不准 NAT 3，将传统 3489 模式下的对称型测为了端口受限锥型。但有时候这些东西用 5780 能测出不同的映射类型，有的可能是因为多次的 Nat，有的是因为内外端口变化，还有的是因为蜂窝的网关防火墙，可能只对同运营商不丢包之类。</br>
同时，光武汉就有 汉口独立城域网（实体BRAS+小范围公网IP）、武汉市电信直连4134，以及云化、池化，备受争议的省网AS 137266（固移融合，电信的核心价值在宽带）.

IP 受限锥型，按照规范的俗称应该叫做 NAT2，请注意区分。公网按俗称应该叫 NAT0，CGNAT 常见的是 NAT1，不是 2；家用路由器限制的端口受限锥型通常称之为 NAT3。除蜂窝网络以外，真正的 NAT4 很少。请不要悲观，请不要万物皆对称的固执退缩思维。</br>
NAT2，又称之为万能 NAT，根据经典的 3489 四象限打洞表，公式可以简化为：小于 6 几乎必通，等于 6 大概率通。</br>
NAT2，真正的 NAT2，IP 受限锥型 ADF 比大熊猫还要稀有。

按照旧标准的话，我总结了一套口诀。口诀就是小于6必通，等于6大概率通，大于6通不了，大于7不如买彩票。

NAT1不是UPnP或端口转发，只是有效期一定时间（例如特定固件实现可能为 5min）的UDP NAT状态表。

严禁混淆 NAT1（Full Cone）、UPnP 与公网 IP 的概念。公网 IP 只是端到端的通行证，而 NAT1 是一种防火墙状态机策略（Endpoint-Independent Mapping/Filtering）。</br>
