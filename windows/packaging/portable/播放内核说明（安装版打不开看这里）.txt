播放内核说明（安装版点了没反应看这里）

【这个文件夹里的播放内核是通用版】
  便携包里的 libmpv-2.dll 是通用版，所有 64 位 CPU 都能用。
  exe 安装包里的是 AVX2 版，按较新的 CPU 优化过。不支持 AVX2 的电脑装了它，点图标会毫无反应。
  不支持的主要是：2013 年以前的老电脑；2020 年以前的奔腾、赛扬，比如 G4560、G5400、G6400、J4125、N5105。
  想知道自己的 CPU 支不支持：打开 PiliBro → 设置 → 电脑位宽与视频流畅度诊断。

【用便携包】
  直接运行这个文件夹里的 pilibro.exe 就行，不用做任何事。
  注意别去点桌面上安装版的快捷方式，那个打开的是安装版。

【安装版打不开，想继续用安装版】
  把这个文件夹里的 libmpv-2.dll 复制到安装目录，替换掉原来的：
  1. 完全退出 PiliBro：关掉窗口后，右下角托盘里如果还有它的图标，右键选「退出 PiliBro」。
  2. 在桌面上右键 PiliBro 的快捷方式，选「打开文件所在的位置」。
     桌面上没有快捷方式的，在开始菜单里右键 PiliBro，选「更多」→「打开文件位置」，再对打开的快捷方式做一次同样的操作。
  3. 打开的文件夹里能看到 pilibro.exe 和 libmpv-2.dll。
     把这个文件夹里的 libmpv-2.dll 拖进去，选「替换目标中的文件」；提示需要管理员权限，点「继续」。
  4. 重新打开 PiliBro。
  以后安装版每次更新都会装回 AVX2 版，再做一遍第 1 到 3 步就行。
